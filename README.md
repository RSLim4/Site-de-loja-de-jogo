# Level Up Store

Site de loja de jogos digitais feito para o projeto de Desenvolvimento Front-End para Web (Universidade Positivo).

Abra o `index.html` no navegador: o site funciona offline.

## Páginas

| Página | Arquivo | Tecnologias |
| --- | --- | --- |
| Início | index.html | HTML, CSS, JS e Bootstrap |
| Catálogo | catalogo.html | HTML, CSS, JS e Bootstrap |
| Jogo | jogo.html | HTML, CSS, JS e Bootstrap |
| Carrinho | carrinho.html | HTML, CSS, JS e Bootstrap |
| Pagamento | checkout.html | HTML, CSS, JS e Bootstrap |
| Entrar | login.html | HTML, CSS, JS e Bootstrap |
| Cadastro | cadastro.html | HTML, CSS, JS e Bootstrap |
| Minha conta | conta.html | HTML, CSS, JS e Bootstrap |
| Lista de desejos | lista-desejos.html | HTML, CSS e JS puros |
| Contato | contato.html | HTML, CSS e JS puros |

## Pastas

- `css`: estilo próprio (style.css) e Bootstrap 5.3.3
- `js`: dados dos jogos, funções comuns e um script por página
- `img`: logo, capas e banners
- `video`: trailer e trilha sonora
- `fonts`: fonte Rubik (local, para funcionar offline)
- `doc`: documentação do projeto
